# Student Performance Analysis Using Python

## Project Overview

This project analyzes student performance using Python and basic data analysis techniques.

The analysis uses study hours, attendance, assignment scores, previous marks, and final marks to identify patterns in student performance.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Key Results

The analysis produced the following results:

- Average Final Marks: 76.00
- Average Study Hours: 4.80 hours
- Average Attendance: 81.50%
- Average Assignment Score: 76.25
- Highest Final Marks: 97
- Lowest Final Marks: 47

The analysis also categorizes students into three performance levels: Excellent, Good, and Needs Improvement.
